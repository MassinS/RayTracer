# 0003: Use Catch2

## Context

The project needs readable, maintainable C++ unit tests to check correctness
and detect regressions, including as mathematical operations and ray-object
intersections are implemented. Alternatives include GoogleTest, doctest, and
Boost.Test. The current starter test uses Catch2's `TEST_CASE` and `REQUIRE`
constructs; CMake fetches Catch2 v3.7.1.

## Decision

Use Catch2 v3.7.1 to write C++ unit tests, integrated with CMake and CTest.

## Status

Proposed

## Consequences

The initial test-enabled CMake configure needs Git and an internet connection
to fetch Catch2. It is an additional dependency that must be built and
maintained with the project.
